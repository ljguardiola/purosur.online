# Releases

The cloud service and the register app are two independently versioned deliverables: `cloud-vX.Y.Z` and `pos-vX.Y.Z`. A merge to `main` that changes the cloud deploys it to staging automatically once its Verify run passes; one that changes the register or a package it uses builds the register's staging installer, kept as an artifact of that run. A register release is named after its installer's version, `pos-v<major>.<minor>.<run number>`: the major and minor come from `apps/pos/package.json` and the run number from the packaging run on `main` that built the installer staging serves, so patch numbers skip between releases. Its promotion attaches that production installer, `Puro Sur Setup <version>.exe`, to the release.
